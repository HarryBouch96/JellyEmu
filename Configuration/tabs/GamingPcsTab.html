Add a gaming PC

Needs Windows 10 or 11 with a graphics card that can encode video (most from the last few years). Name it, then run the command shown on that PC. It installs everything in C:\JellyEmu and asks for administrator rights; your own copy of Sunshine, if you have one, is left alone.

Paste this into PowerShell on the new PC. The code in it works once, for 30 minutes.


            
            
        

    


    
    

        
Stream address

        

            The HTTPS address your reverse proxy serves game streams at. It checks each viewer's Jellyfin login with
            JellyEmu, then sends them on to the right gaming PC.
        

        
        

            Reverse proxy (Caddy) configuration
            

                For Caddy on the same machine as Jellyfin (change 127.0.0.1:8096 if it isn't). Add your usual
                tls settings. Adding more gaming PCs never needs a change here.
            

            

        


        
Library paths

        

            Where gaming PCs find the games: each folder as Jellyfin sees it, and the same folder from a gaming PC
            (usually a network share). Setup asks for the share's sign-in on each PC if it needs one.
